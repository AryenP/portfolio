Projects

A selection of systems work across LLM inference, computer vision, evaluation, and edge deployment.

LLM Inference and Evaluation Platform

A self-hosted LLM serving project built around vLLM, FastAPI, Docker, and AWS. I treated serving as a systems problem: latency, caching, quantization, and evaluation all had to be measurable.

  • Used AWQ quantization and prefix caching to reduce time-to-first-token from 840ms to 310ms.
  • Built a LangGraph evaluation workflow for retrieval quality and hallucination checks.
  • Ran the evaluation automatically through GitHub Actions on every commit.

Mangrove Monitoring with Scripps

Research work with Engineers for Exploration at UC San Diego focused on satellite-image segmentation for mangrove coverage estimates and making the resulting model useful to researchers.

  • Trained and evaluated a U-Net segmentation model on 18,400 labeled satellite tiles.
  • Raised validation IoU from 0.71 to 0.78.
  • Built supporting infrastructure for querying field reports more easily.

Edge Object Detection on NVIDIA Jetson

A computer-vision deployment project for running object detection away from the cloud, with the model optimized for useful throughput under edge power constraints.

  • Deployed a YOLO model to NVIDIA Jetson hardware with TensorRT INT8 quantization.
  • Reached 27 FPS at 11W in the tested configuration.
  • Designed around field inference where network access cannot be assumed.
