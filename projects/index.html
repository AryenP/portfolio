Projects

LLM Inference and Evaluation Platform

A self-hosted LLM serving project built around vLLM, FastAPI, Docker, and AWS. The goal was to treat model serving like a real systems problem: latency, caching, quantization, and evaluation all had to be visible instead of hidden behind a demo.

  • Used AWQ quantization and prefix caching to reduce time-to-first-token from 840ms to 310ms.
  • Built a LangGraph evaluation workflow for retrieval quality and hallucination checks.
  • Ran the eval automatically through GitHub Actions on every commit.

Mangrove Monitoring with Scripps

Research work with Engineers for Exploration at UC San Diego, focused on satellite-image segmentation for mangrove coverage estimates. I worked on the model pipeline, serving path, and evaluation pieces that make the result useful to researchers instead of just technically interesting.

  • Trained and evaluated a U-Net segmentation model on 18,400 labeled satellite tiles.
  • Raised validation IoU from 0.71 to 0.78 in the resume version I am using for internship applications.
  • Built supporting infrastructure so non-technical researchers could query field reports more easily.

Edge Object Detection on NVIDIA Jetson

A computer-vision deployment project for running object detection away from the cloud. The main challenge was making the model small and fast enough to be useful on edge hardware while keeping the result measurable.

  • Deployed a YOLO model to NVIDIA Jetson hardware with TensorRT INT8 quantization.
  • Reached 27 FPS at 11W in the tested configuration.
  • Framed the project around field inference, where network access cannot be assumed.
