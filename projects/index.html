LLM Inference and Evaluation Platform

A self-hosted LLM serving project built around vLLM, FastAPI, Docker, and PostgreSQL. I treated serving as a systems problem: latency, quantization, retrieval quality, and cost all had to be measured rather than asserted.

  • Cut time-to-first-token from 165ms to 107ms on Qwen3-8B by serving a 4-bit AWQ checkpoint in place of BF16 on a single L40S.
  • Found that hybrid BM25 plus dense retrieval did not beat dense alone over 12,000 arXiv abstracts, and reported the null result.
  • Gated the evaluation in GitHub Actions so a retrieval regression below the recorded baseline fails the build.
